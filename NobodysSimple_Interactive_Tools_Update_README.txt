NOBODY'S SIMPLE — INTERACTIVE TOOLS UPDATE

This package contains four replacement website files:
- features.mjs
- interactive-tools.mjs
- styles.css
- sw.js

MANUAL INSTALL
1. Extract this ZIP on your device.
2. Open the NobodysSimple/nobodyssimple GitHub repository.
3. Choose Add file → Upload files.
4. Upload those four files into the repository root (the same level as index.html). If GitHub says a file already exists, the commit will replace its contents.
5. Commit the changes to main. GitHub Pages will publish after the Actions workflow completes.
6. Refresh the site. The service-worker cache version is updated; if an older view remains, close and reopen the browser tab.

Do not upload this README file to the website repository.
